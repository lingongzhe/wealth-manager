# 理财管家 · 银行卡理财收益管理

一个**纯前端**的银行卡理财收益管理应用,无需后端与数据库,数据保存在浏览器本地。帮助你把多张银行卡的理财/存款收益集中管理,一眼看清每笔资金何时到期、能赚多少利息。

## 功能特性

- **多卡管理**:支持同时添加多张银行卡,分别记录本金与年化利率
- **收益测算**:自动计算每张卡的到期利息与收益明细
- **到期提醒**:按存入日期推算到期时间,避免资金闲置
- **本地存储**:所有数据保存在浏览器 `localStorage`,无需联网与登录,隐私安全
- **响应式界面**:适配桌面与移动端,随时随地查看

## 使用方式

**方式一:直接打开**

将 `index.html`(或 `理财管家.html`)用任意现代浏览器打开即可使用,无需安装、无需构建。

**方式二:本地静态服务(推荐)**

```bash
# 任选其一
python -m http.server 8000
# 或
npx serve .
```

然后访问 `http://localhost:8000`。

**方式三:GitHub Pages 在线访问**

本仓库已配置 GitHub Pages 支持,可直接通过 Pages 地址在线使用,同样数据仅保存在你的浏览器本地。
